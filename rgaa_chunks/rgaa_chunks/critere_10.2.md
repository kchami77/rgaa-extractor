# Critère 10.2 — Présentation de l’information

**Dans chaque page web, le contenu visible porteur d’information reste-t-il présent lorsque les feuilles de styles sont désactivées ?**

_Source : https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests#10.2_

---

## Test 10.2.1

Dans chaque page web, l’information reste-t-elle présente lorsque les feuilles de styles sont désactivées ?

**Méthodologie :**

1. Désactiver les styles (CSS) du document ;
2. Comparer le document dépourvu de styles avec le document mis en forme ;
3. Vérifier si dans le document dépourvu de styles, les contenus visibles porteurs d'information restent présents ;
4. Si c’est le cas, **le test est validé**.

_Réf : https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests#10.2.1_
