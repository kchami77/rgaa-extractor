# Critère 8.8 — Éléments obligatoires

**Dans chaque page web, le code de langue de chaque changement de langue est-il valide et pertinent ?**

_Source : https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests#8.8_

---

## Test 8.8.1

Pour chaque page web, le code de langue de chaque changement de langue vérifie-t-il ces conditions ?

- Le code de langue est valide ;
- Le code de langue est pertinent.

**Méthodologie :**

1. Pour chaque passage de texte validé au test 8.7.1, vérifier que :
 - L’indication de langue est valide ;
 - L’indication de langue est pertinente.
2. Si c’est le cas, **le test est validé**.
