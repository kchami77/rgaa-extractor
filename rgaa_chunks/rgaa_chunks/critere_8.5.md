# Critère 8.5 — Éléments obligatoires

_Source : https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests#8.5_

## Test 8.5.1

Chaque page web a-t-elle un titre de page (balise `<title>`) ?

**Méthodologie :**

Test 8.5.1

1. Retrouver dans le document le titre structuré au moyen d’un élément `<title>` ;
2. Si c’est le cas, **le test est validé**.
