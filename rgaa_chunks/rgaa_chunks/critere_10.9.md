# Critère 10.9 — Présentation de l’information

**Dans chaque page web, l’information ne doit pas être donnée uniquement par la forme, taille ou position. Cette règle est-elle respectée ?**

_Source : https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests#10.9_

---

## Test 10.9.1

Dans chaque page web, pour chaque texte ou ensemble de textes, l’information ne doit pas être donnée uniquement par la forme, taille ou position. Cette règle est-elle respectée ?

**Méthodologie :**

1. Retrouver dans le document les informations d’un texte données par la forme, la taille ou la position ;
2. Pour chaque information donnée par la forme, la taille ou la position, vérifier qu’il existe un autre moyen de récupérer cette information ;
3. Si c’est le cas pour chaque information, **le test est validé**.

_Réf : https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests#10.9.1_
