# Critère 8.1 — Éléments obligatoires

**Chaque page web est-elle définie par un type de document ?**

_Source : https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests#8.1_

---

## Test 8.1.1

Pour chaque page web, le type de document (balise `doctype`) est-il présent ?

**Méthodologie :**

1. Retrouver dans le document la balise DOCTYPE (par exemple `<!DOCTYPE html>`) ;
2. Vérifier que :
 - La balise DOCTYPE est placée avant la balise `<html>` ;
 - Le type de document est valide.
3. Si c’est le cas, **le test est validé**.

_Réf : https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests#8.1.1_
