# Critère 10.10 — Présentation de l’information

**Dans chaque page web, l’information ne doit pas être donnée par la forme, taille ou position uniquement. Cette règle est-elle implémentée de façon pertinente ?**

_Source : https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests#10.10_

---

## Test 10.10.1

Dans chaque page web, pour chaque texte ou ensemble de textes, l’information ne doit pas être donnée uniquement par la forme, taille ou position. Cette règle est-elle implémentée de façon pertinente ?

**Méthodologie :**

1. Retrouver dans le document les informations d’un texte données par la forme, la taille ou la position ;
2. Pour chaque information donnée par la forme, la taille ou la position, vérifier que le moyen alternatif de récupérer cette information est pertinent, c’est-à-dire qu’il permet de transmettre l’information dans tous les contextes de consultation et pour tous les utilisateurs.
3. Si c’est le cas pour chaque information, **le test est validé**.

_Réf : https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests#10.10.1_
