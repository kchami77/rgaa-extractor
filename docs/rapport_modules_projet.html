🎯 En une phrase : c'est quoi ce projet ?

RGAA Constat Extractor est un outil web qui aide les professionnels de l'accessibilité numérique à automatiser une tâche répétitive : extraire les erreurs d'accessibilité depuis leurs rapports Word, les organiser, les analyser, et les interroger via un assistant intelligent.

ℹ️ Le RGAA
Le RGAA (Référentiel Général d'Amélioration de l'Accessibilité) est le guide officiel français qui définit les règles pour rendre les sites web accessibles à tous, y compris aux personnes handicapées (malvoyants, non-voyants, etc.).

Module 1

🎻 Le Chef d'Orchestre (Le Serveur)

server/_core/index.ts  |  package.json  |  .env

ℹ️ Qu'est-ce qu'un serveur ?
Un serveur, c'est comme un restaurant. Il attend que des clients (votre navigateur) passent des commandes, les traite, et renvoie le résultat. Il tourne 24h/24, invisible mais indispensable.

Ce que fait ce module au démarrage

  • 🏪 Ouvre le restaurant — Express.js démarre et écoute sur le port 3000
  • 📋 Charge le menu RGAA — Les 106 critères d'accessibilité sont chargés en mémoire
  • 🧠 Vérifie le stock IA — Si ChromaDB est vide, il la remplit automatiquement en arrière-plan
  • 🗺️ Configure les routes — Définit les URLs acceptées
  • 🔍 Cherche un port disponible — Si 3000 est pris, il essaie 3001, 3002…

Les commandes pour lancer le projet

CommandeCe que ça faitQuand l'utiliser
pnpm installInstalle tous les outilsUne seule fois au début
pnpm db:pushCrée les tables MySQLAprès une mise à jour
pnpm devLance le serveur en devTous les jours
pnpm mcpLance l'interface ClaudePour l'IA avancée
Module 2

📖 Le Lecteur de Documents Word (Parser)

server/parser.ts

ℹ️ Qu'est-ce qu'un parser ?
Un parser, c'est comme un assistant qui lit un rapport papier à votre place et le retranscrit dans un tableau Excel structuré. Il comprend la mise en forme et sait où chercher les informations.

Les 3 étapes du parsing

1
Convertir le Word en texte lisible
mammoth.js → texte brut + HTML
2
Trouver la bonne section
Cherche "Descriptions des erreurs d'accessibilité" (dernière occurrence)
3
Extraire chaque erreur ligne par ligne
Détecte les marqueurs "Impact : Bloquant/Majeur/Mineur"

Exemple concret

Ligne dans le Word :
"Page d'accueil – Impact : Bloquant L'image ne possède pas d'alternative textuelle"

↓ Constat extrait :
  Critère     : 1.2
  Localisation: Page d'accueil
  Impact      : Bloquant  🔴
  Texte       : "L'image ne possède pas d'alternative textuelle"

Données extraites pour chaque erreur

ChampExemple
Numéro de critère1.2
ThématiqueImages
ImpactBloquant Majeur Mineur
LocalisationPage d'accueil
Problème utilisateurImpossible pour un non-voyant…
Texte du constatL'image ne possède pas d'alternative…
💡 Tip
Si un rapport ne s'importe pas correctement, le parser génère des messages de diagnostic qui expliquent exactement ce qui n'a pas été trouvé (section manquante, format inattendu, etc.).

Imaginez une armoire avec des tiroirs bien étiquetés. Chaque tiroir contient un type d'information précis. Vous pouvez y ajouter des fiches, en chercher, les modifier ou les supprimer à tout moment.

Module 4

📞 Le Téléphone Entre Client et Serveur (API tRPC)

server/routers/

ℹ️ Qu'est-ce qu'une API ?
Une API, c'est comme le menu d'un restaurant. Elle liste tout ce que le client (navigateur) peut demander au serveur. tRPC est une façon moderne de créer cette communication avec une sécurité maximale.

Les 6 groupes de fonctions

appRouter
├── auth            → "Qui suis-je ?" / "Déconnexion"
├── audit           → Gérer les rapports d'audit
├── criteria        → Consulter le référentiel RGAA
├── findingTemplates → Bibliothèque de constats
├── hub             → Poser des questions à l'IA
└── settings        → Configurer l'application

Fonctions principales du router audit

FonctionTypeCe qu'elle fait
uploadReportÉcritureReçoit et stocke le fichier Word
processReportÉcritureLance le parsing + extraction des constats
getUserReportsLectureListe tous les rapports de l'utilisateur
getEnrichedFindingsLectureRécupère les constats avec filtres
deleteReportSuppressionSupprime un rapport et ses constats
⚠️ Warning
Certaines fonctions sont protégées (nécessitent d'être connecté). Le système vérifie automatiquement une session sécurisée avant chaque action sensible.

Module 6

🔗 La Connexion avec les IA Externes (MCP)

server/mcp.ts

ℹ️ Qu'est-ce que le MCP ?
MCP (Model Context Protocol) est comme un port USB universel pour les IA. Il permet à un assistant comme Claude Desktop de se brancher directement à l'application et d'utiliser toutes ses fonctionnalités.

Ce que Claude peut faire grâce au MCP

OutilCe que Claude peut faire
ask_accessibilityPoser une question sur l'accessibilité
analyze_codeAnalyser du HTML et détecter des problèmes
suggest_fixDemander une correction pour un problème
get_report_findingsConsulter les constats d'un rapport
search_findingsChercher des constats avec des filtres
validate_findingValider et indexer un constat dans la base IA

Comment l'activer : pnpm mcp — s'utilise avec Claude Desktop ou Claude Code.

Collecte automatique d'informations depuis des sources en ligne
Serveur
Programme qui répond en permanence aux demandes des navigateurs
tRPC
Système de communication typé entre frontend et backend
TypeScript
JavaScript avec des règles plus strictes pour éviter les erreurs

Représentation mathématique du sens d'un texte, utilisée par l'IA
